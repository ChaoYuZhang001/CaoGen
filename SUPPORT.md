# CaoGen Support and Feedback / 支持与反馈

[中文](#中文) | [English](#english)

## 中文

请按问题类型选择公开入口，避免同一问题在多个地方重复提交：

| 需要 | 入口 | 适合内容 |
|---|---|---|
| 使用帮助 | [Q&A Discussions](https://github.com/ChaoYuZhang001/CaoGen/discussions/categories/q-a) | 安装、Provider 配置、工作流入口和使用方式 |
| 产品反馈 | [General Discussions](https://github.com/ChaoYuZhang001/CaoGen/discussions/categories/general) | 使用体验、卡点、哪些地方有效或难懂 |
| 改进建议 | [Ideas Discussions](https://github.com/ChaoYuZhang001/CaoGen/discussions/categories/ideas) | 从真实用户问题出发的改进方案 |
| 可复现缺陷 | [Bug Report](https://github.com/ChaoYuZhang001/CaoGen/issues/new?template=bug_report.yml) | 当前发布能力中的稳定复现问题 |
| 安全问题 | [SECURITY.md](./SECURITY.md) | 漏洞、凭据泄露或需要私下处理的报告 |

公开 Issue、Pull Request 和 Discussion 会在 **48 小时内收到维护者首次回应**。首次回应是确认、分流或给出下一步，不代表 48 小时内完成修复、review 或合并。定时只读工作流每 6 小时检查一次当前逾期项；自动回复不计作维护者回应。

提交公开内容前，请删除 API Key、Token、私有仓库内容、个人信息和敏感本机路径。路线图功能尚未上线时，请明确写成建议，不要写成当前能力。

## English

Choose one public channel for each topic so the same request is not duplicated:

| Need | Channel | Best for |
|---|---|---|
| Usage help | [Q&A Discussions](https://github.com/ChaoYuZhang001/CaoGen/discussions/categories/q-a) | Installation, provider setup, workflow entry points, and how-to questions |
| Product feedback | [General Discussions](https://github.com/ChaoYuZhang001/CaoGen/discussions/categories/general) | Experience reports, friction, and what was useful or unclear |
| Improvement idea | [Ideas Discussions](https://github.com/ChaoYuZhang001/CaoGen/discussions/categories/ideas) | Focused proposals grounded in a real user problem |
| Reproducible bug | [Bug Report](https://github.com/ChaoYuZhang001/CaoGen/issues/new?template=bug_report.yml) | Reproducible failures in currently available capabilities |
| Security issue | [SECURITY.md](./SECURITY.md) | Vulnerabilities, credential exposure, or reports that need private handling |

Every public issue, pull request, and discussion will receive an **initial maintainer response within 48 hours**. An initial response means acknowledgment, routing, or a concrete next step; it is not a promise to complete a fix, review, or merge within 48 hours. A read-only scheduled workflow checks for currently overdue items every six hours. Automated replies do not count as maintainer responses.

Before posting publicly, remove API keys, tokens, private repository content, personal information, and sensitive local paths. Describe unbuilt roadmap work as a proposal, not as a current capability.
